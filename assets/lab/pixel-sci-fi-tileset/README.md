# Pixel Sci-Fi Tileset (16x16)
83 free pixel-art tiles and sprites for top-down sci-fi games. By reodesuxz.

Contents: 20 floors (steel, dark, blue, green, white, rust, hazard, holo grid, vent, 3-frame conveyor, acid, space), 16 wall pieces (4 styles), 7 doors/stairs, 18 props, 5 traps, 7 items, 8 enemy frames, 2 player sprites.
Files: PNG/native (16x16), PNG/x4, spritesheet.png + spritesheet.json (x,y,w,h), sample_scene.png.
Engines: Unity, Godot, GameMaker, Tiled, Construct, Phaser. Use Point/Nearest filtering, no compression.
